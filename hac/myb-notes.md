## Запуск

Скрипт предназначен для `localhost:3000` и проверяет адрес перед запуском. Выполни содержимое `myb.js` в Console один раз, затем вызывай функцию:

```js
const stopBlockTest = startBlockTest({ maxClicks: 50, jitterMs: 50 });
stopBlockTest?.(); // Досрочная остановка
```

Аргумент — объект настроек, аналогичный props: `maxClicks` — положительное целое число нажатий (по умолчанию 50), `jitterMs` — целая неотрицательная величина отклонения в миллисекундах (по умолчанию ±50). После достижения лимита таймер останавливается.

```js
startBlockTest({ maxClicks: 10, jitterMs: 0 });
```

При `jitterMs: 0` используется исходная последовательность без случайного отклонения. Фактическое время зависит от планировщика браузера.

Для замены текущего запуска передай его функцию остановки явно:

```js
let stop = startBlockTest({ maxClicks: 50, jitterMs: 50 });
stop = startBlockTest({ maxClicks: 10, jitterMs: 0, previousStop: stop });
stop?.();
```

Без `previousStop` вызовы независимы. Общего изменяемого состояния и IIFE нет. Старые функции остановки не влияют на новые запуски. Объект `window` не изменяется. Элемент ищется один раз; при его удалении тест останавливается.




Если адрес не подходит или элемент не найден, функция возвращает undefined без ошибки. После каждого отправленного pointerdown в консоли выводится номер нажатия. Это подтверждает отправку события, а не его зачёт игрой.


## Вторая версия: координаты события

`myb-v2.js` — отдельная версия с функцией `startBlockTestV2`. Ограничение на `localhost:3000` сохранено.

```js
const stopV2 = startBlockTestV2({
  maxClicks: 50,
  jitterMs: 50,
  positionJitterPx: 5,
});
stopV2?.();
```

`positionJitterPx` задаёт случайное отклонение по каждой оси от центра элемента (по умолчанию ±5 пикселей, ограничено размерами элемента). Ноль отключает отклонение координат. В консоль выводятся координаты отправленного события. Событие по-прежнему отправляется непосредственно на `.game-page-root`, без выбора получателя по координатам. Эти координаты не меняют точность установки игрового блока в просмотренном обработчике.

## Параметры функций

Вторая функция называется `startBlockTestV2` (не `startBlockTest2`). Обе принимают один необязательный объект настроек.

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `maxClicks` | `50` | Лимит отправленных нажатий. Положительное целое число. |
| `jitterMs` | `50` | Отклонение от базовой задержки на ±jitterMs миллисекунд. Неотрицательное целое число; `0` отключает случайность. Итоговая задержка не меньше 1 мс. |
| `previousStop` | `undefined` | Функция остановки предыдущего запуска. Вызывается после начальных проверок. Без неё запуски независимы. |
| `positionJitterPx` | `5` | Только V2: отклонение координат события от центра по каждой оси в CSS-пикселях. Ограничено половиной размера элемента; `0` задаёт центр. Положение блока не меняет. |

Возвращается функция остановки либо `undefined`, если начальные проверки не прошли. Используй `stop?.()`. Требования к `maxClicks` и `jitterMs` описывают ожидаемые значения: текущий код не валидирует эти два параметра.
